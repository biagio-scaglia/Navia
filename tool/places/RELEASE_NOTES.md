Offline place datasets for the Navia app, regenerated monthly by the
`Places data` workflow from [Geofabrik](https://download.geofabrik.de)
extracts of OpenStreetMap.

Each `places-<region>.jsonl.gz` file holds the points of interest of one
Italian macro-region (restaurants, cafés, supermarkets, pharmacies,
hospitals, museums, attractions, parks, hotels, public transport, parking,
fuel stations and ATMs), one JSON object per line. `manifest.json` lists the
files with their size, SHA-256 checksum, number of places and bounding box.
